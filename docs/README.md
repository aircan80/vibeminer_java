# Project documentation

These versioned documents are the formal project specifications. A clean checkout contains the material needed to continue development; GitHub Issues records current delivery status.

[Alpha.7](https://github.com/aircan80/vibeminer/releases/tag/v0.1.0-alpha.7) is the latest published prerelease: exact `8baaadbfb78732b39f2f2c37809718e76d61309d`, annotated tag `ebc83ad6aa90424382d594e9d0670040ff631c73`. [Publication run 39163051502](https://github.com/aircan80/vibeminer/actions/runs/39163051502) passed all four native targets and fifteen Linux UI workflows. All twelve final assets were independently downloaded and verified. Java is bundled; packages are unsigned and macOS is not notarized. See [release scope and limits](releases/v0.1.0-alpha.7.md).

The preview connects product-first Discover → complete required metadata Open → Atlas C overview → persistent background Download all/On demand. Dated chooser readiness remains historical. Complete live-build compatibility, whole-build capacity preflight and physical/shared accounting remain unfinished; this is not milestone completion.

The latest completed cross-platform development checkpoint is exact `8baaadbfb78732b39f2f2c37809718e76d61309d`: [CI 39162118853](https://github.com/aircan80/vibeminer/actions/runs/39162118853) passed all four native targets and fifteen Linux UI workflows. A clean immutable checkout passed **2,144 Java tests**, **40 Python helpers**, Linux package verification, bundled-runtime self-test and JavaFX smoke.

The actual Discover → Open → C → background Download all → Fully downloaded → On demand → offline restart journey passed four window/text-scale cases: **956 assertions and 56 captures**. Dated chooser observations remain explicitly historical; current Open detects deliberate payload corruption without implicit repair. Independent visual review accepted the exact-source screenshots. [Readiness and mining evidence](design/build-readiness-native/README.md) records source, selected captures and limits. CI independently passed the same 956 assertions and zero metadata/content HTTP attempts on all four fresh-JVM restarts. Earlier [mining evidence](design/build-mining-native/README.md) remains historical.

Bulk qualification uses authored transport and one 68-byte payload. Complete retention of an entire live WoW build through the new bulk composition remains unverified; bounded formats are not broad Retail compatibility. Dedicated integration checks separately cover shared-transfer priority, persisted resume, injected publication I/O failures and seven actual process-death boundaries. Injected ENOSPC is not a physical full-volume test, and process termination is not a power-loss proof.

The alpha.7 tag, publication and independent final-asset verification are complete as recorded above. Final milestone acceptance is tracked in Issues; payload free-space/headroom preflight (#102) remains unfinished, so this preview does not complete the milestone.

Current implementation is [milestone 5](https://github.com/aircan80/vibeminer/milestone/5): guided Discover → exact Open Build → only C overview, backed by real metadata/catalog/storage and On demand/Download all. Open requires the complete declared metadata proof closure; unknown or unfetched required metadata is Not ready. Only derived payload inventory/indexing may still be Preparing after C opens. Full requires the complete declared ROOT/IN/applicable DL content/dependency closure, not a convenient supported subset. [Milestone 6](https://github.com/aircan80/vibeminer/milestone/6) selects top navigation/Tables/optional FK labels only after milestone 5. Locale #114, asynchronous request #115, semantic research #116 and entity comparison #117 remain future work and do not expand milestone 5.
