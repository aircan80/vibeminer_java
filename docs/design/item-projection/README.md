# Atlas Item physical-row references

These 18 scene-only PNGs record the accepted native Atlas physical-row interface at source `1cea99f` (including the schema9 backend). The final `CaptureItemProjectionWorkflow` run passed **85 assertions across two application JVMs** on an isolated Linux display. Independent visual review accepted the 100% and 200% presentation. The supervisor was corrected and independently reviewed before this final run: temporary storage is deleted only after worker termination is confirmed; an unretired worker preserves its store. Its no-display deterministic self-test also passed.

The fixture authors **61 physical rows and one excluded copy declaration**. It exercises the real retained Item reader, BLTE/WDC5 interpretation, bundled pinned schema, application service, CAS and SQLite projection. Root/EN association authentication and root-membership presentation use an explicit synthetic proof port; this is **not official TACT/root/EN authentication evidence**. No HTTP or real game content is used, no game installation is read, and the normal user catalog is never opened. Field numbers are authored fixture values, not actual Item records.

The accepted scope is physical rows in the admitted section. Copies and other sections are not indexed. Candidate field attribution remains visible, names and icons are unavailable, and full decoded CKey verification is not established. The four proof dimensions remain separate. Encoded retention does not imply a ready Item projection.
