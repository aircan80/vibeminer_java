# Top navigation: Home and Tables

[Open Home](home.html) · [Open Tables](tables.html)

Paired alternative under [#111](https://github.com/aircan80/vibeminer/issues/111). Top navigation switches application areas; each area can have its own internal navigation. Tables keeps the Explorer catalogue on the left, breadcrumb trail and 340px inspector. Catalogue selection starts a new trail; relationships extend it. Home uses the selected C overview and retains background download controls within Build readiness. Items and other future areas are disabled placeholders.

The existing sidebar alternatives remain available for comparison. All quantities and rows are illustrative; no downloads or persistence occur. Schema attribution and limitations remain documented in [the table research](../tables/RESEARCH.md). Top area navigation was selected on 2026-10-18. Implementation follows completion of the current guided-discovery/build-overview milestone; this design does not expand that milestone.

Browser review: rendered Home and Tables at 1440 × 1000, visually reviewed both, verified reciprocal area links, catalogue presence, linked breadcrumb navigation/reset, and no page overflow. Home download-mode interactions retain their design-preview behavior.
