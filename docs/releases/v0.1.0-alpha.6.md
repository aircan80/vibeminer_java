## Included changes

- Explicitly prepare an already retained exact Item/ItemSparse source pair in the supported enUS cohort. Browse physical Item-ID pages, inspect an exact ID and see attributed Display candidates. Empty names, excluded copy declarations, missing physical names and missing Item anchors remain distinct; both sources and proof limits remain visible.
- Explicitly search that prepared pair with case-sensitive literal Unicode substring matching. Preserve spaces and normalization; percent, underscore and backslash are ordinary characters. No search on typing, automatic preparation or download. Bounded verified scans return scoped matches, never whole-build absence; exhausted bounds fail without false partial/no-match success.
- Separately check and approve known-cost repair of the exact original canonical root/install representation. Preserve original receipts and record new repair observations separately. No alternate encoding, automatic fallback or silent retry. Uncertain publication requires explicit local verification. Concurrent consumers share only the same exact issued plan, with at most 32 lifetime consumers and four actual jobs; distinct issuances and cross-build contenders remain BUSY.
- Reject malformed UTF-16 interpretation metadata before hashing/persistence. ROOT crash recovery has actual process-halt/reopen evidence with zero-HTTP recovery. Native post-STRUCTURE uncertainty is ROOT-specific; symmetric INSTALL uncertainty has unit coverage only.

## Explicit limits

Names and search cover admitted physical candidate rows only; copies and other sections remain excluded. No complete decoded table CKey, complete localized catalog, general schema browsing, thumbnails, obtainable-reward inference or server-state assertion is implied. Broad #21 still needs validated relations and separately scoped official-build research evidence.

Search includes source replay and integrity scans in addition to its bounded linear match scan; #88 profiling remains separate, with no constant-time or invented latency guarantee. Historical availability #18 and safe deletion/GC #19 remain unfinished. #91 single-record JSON export is excluded; bulk/CSV, notes, comparisons and complete historical/game archives are absent. Repair does not authorize different encodings, replacement or game-install reads.

Packages bundle Java for Windows x64, Linux x64, macOS Intel and macOS ARM64; native qualification and independent final-asset verification passed. They are unsigned and macOS packages are not notarized unless actual signing evidence is separately recorded. No separate Java or game installation is required.
