## Included workflow

Choose a WoW product and exact build in product-first Discover, select **Open Build**, and enter only the Atlas C build overview. Discovery combines advertised and locally remembered references, regional provenance and stable locally first-seen/New state. Open retains and verifies the complete required metadata for the admitted formats, including published DS. Retained metadata can reopen offline.

The overview separates current readiness, retained percentage and download activity. Switch between **On demand** and **Download all**; authorized work persists across restart, interactive requests receive priority, and switching off background demand preserves shared retained bytes. Identical physical content uses the existing app-owned canonical store. Discover's dated last-checked readiness observations are historical; Open assesses current proof and availability. Selection itself does no content hashing or download.

**Fully downloaded** means complete verified encoded retention of the admitted declared scope. It does not establish decryption, decoded tables, a runnable installation or upstream availability of arbitrary older builds. Unsupported required metadata cannot become an empty successful scope.

## Evidence and limits

Clean local qualification at the exact source passed **2,144 Java tests**, zero failures/errors/skips, **40 Python helpers**, Linux packaging, bundled-runtime self-test and JavaFX smoke. The actual authored-service journey passed **956 assertions/56 captures** at 1440×1100 and 1280×800, each at 100% and 200% application text. Independent visual review accepted the screens; [selected captures and results](../design/build-readiness-native/README.md) are versioned. The tag CI independently passed the same 956 assertions and zero metadata/content HTTP attempts in all four fresh-JVM restarts. A deliberate authored-payload corruption preserves the chooser's dated historical Full observation, while current Open reports Partial/corruption without implicit replacement.

This vector uses authored transport and one 68-byte payload. **Complete retention of an entire live WoW build through the new bulk composition remains unverified.** Existing official protocol evidence does not establish this complete union/retention claim. Bounded admitted formats/routes are not broad Retail compatibility or a throughput result. Linux research/UI workflows are not every-platform usability or accessibility certification; the four native targets separately pass bundled launch/storage smoke.

Dedicated actual integration tests cover shared priority, persisted resume, injected pre/post-move publication I/O faults and seven process-death boundaries. Injected ENOSPC is not a physically filled-volume test. Process termination is not a power-loss guarantee, and not every failure automatically heals.

Remaining milestone work stays open: payload capacity/headroom preflight (#102) and physical/shared/derived-overhead measurements (#104). This version has finite acquisition budgets and safe publication failure, but does not establish that the disk can hold an entire selected build. Those unimplemented physical measurements remain Unknown. Detailed guided failed-job diagnosis/retry is future #119; Retry retention retries activation, not failed members. Corrupt or uncertain bytes are not silently replaced.

Tables/top navigation, locale switching, monitoring, semantic research, comparisons, cleanup/GC and arbitrary historical-build availability remain future scope. Existing accepted research regressions remain available within their previously documented limits. This preview does not complete milestone 5. Catalog migration 21 is forward-moving; older app versions may reject an upgraded catalog.

Packages bundle Java for Windows x64, Linux x64, macOS Intel and macOS ARM64. No game installation or separate Java installation is required. They are unsigned and macOS is not notarized. Intel retains `es2,sw`.
