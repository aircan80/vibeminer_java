# VibeMiner 0.1.0-alpha.4

Test build of VibeMiner, a standalone JavaFX research workbench. Portable packages include Java; no game installation or separate Java installation is required.

This release adds explicit selected encoded-file retention, exact-variant offline reopening, and Database → Item physical-row browsing for the admitted `wow` / US / `12.1.5.70448` / `enUS` cohort. Prepare supported rows explicitly, browse bounded numeric-ID pages, look up an exact Item record ID, and inspect four attributed integer candidates with source evidence.

Copies and other sections remain unindexed. Complete encoded verification and partial row interpretation do not establish a whole decoded Item CKey or complete table coverage. Item names, icons, name search, general table filtering, comparisons, exports, cleanup and complete historical archives are unfinished. Strong alternate-encoding metadata reuse and metadata repair are not enabled in this revision.

Discovery, saved metadata workspaces, verified install-list inspection and exact FileDataID root-membership lookup remain available. VibeMiner reads only official CDN sources and its own storage.

Qualified source: `891a9c4`. Validation includes 994 Java cases, Linux bundled SQLite/CAS and JavaFX launch, all four native targets, seven native UI workflows and nine offline protocol entrypoints. The Item UI workflow passed 85 assertions across two JVMs using authored data and zero HTTP; its root/EN proof port is synthetic. This is scoped acceptance, not live whole-table or assistive-technology certification.

Choose the package for Windows x64, macOS ARM64, macOS Intel or Linux x64. Each package has a SHA-256 checksum and commit-bound build manifest. Packages are unsigned and not notarized. See BUILDING.md and docs/PLAN.md in the repository for details and remaining scope.
